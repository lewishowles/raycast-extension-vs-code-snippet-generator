# VS Code snippet generator changelog

## [1.0.0] - 2026-06-19

### Added

- Generate VS Code snippets from pasted code with automatic escaping
- Optional description field
- Output mode selector: snippet entry, snippet object, or snippet file
- Insert mode: write directly to a VS Code snippet file via a file dropdown
- Duplicate-title detection with explicit Overwrite action
- Escape mode toggle: snippet syntax (default) or literal
